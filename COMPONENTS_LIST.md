# COMPONENTS LIST
## Smart Motion Light with Battery Protection

The following components are used in the development of this project:

### 1. ESP32 Development Board
Acts as the main controller and processes the sensor inputs.

### 2. PIR Motion Sensor (HC-SR501)
Detects human movement within the sensing area.

### 3. Relay Module
Controls the ON/OFF operation of the lighting load.

### 4. Lithium-ion Battery (18650)
Provides rechargeable battery power to the system.

### 5. Battery Voltage Sensor
Monitors the battery voltage.

### 6. ACS712 Current Sensor
Measures the current flowing through the circuit.

### 7. LED Lighting Load
Acts as the lighting output of the system.

### 8. Breadboard
Used for assembling and testing the electronic circuit.

### 9. Jumper Wires
Used to establish electrical connections between components.

### 10. USB Cable / Power Supply
Used for programming the ESP32 and supplying power.
